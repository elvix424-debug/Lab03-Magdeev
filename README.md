## ПР3. Ответы на контрольные вопросы

1. Разницы в результате нет, x += 5 это просто короче записано чем x = x + 5.

2. x++ сначала отдаёт старое значение а потом прибавляет 1, а ++x сначала прибавляет 1 и отдаёт уже новое значение.

3. Всегда bool, то есть true или false.

4. Это когда вторая часть не проверяется если уже понятно какой будет ответ. В && если первое false то дальше не смотрит, а в || если первое true то тоже дальше не смотрит. Например name != null && name.Length > 0, если name пустой (null) то длину проверять не будет и программа не упадёт.

5. Сначала умножение и деление: 2 * 3 = 6 и 4 / 2 = 2. Потом слева направо: 10 - 6 = 4, 4 + 2 = 6. Ответ 6, в коде тоже получилось 6.

6. Потому что так код легче читать и не надо вспоминать какой оператор главнее, и меньше шанс ошибиться.
